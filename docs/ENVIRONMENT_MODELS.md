# 환경 모델 연결

`.modeling-dev/Art/LowPoly/environment`에서 건물 15개, 도로 6개, 소품 12개의 OBJ를 가져왔다.
게임 배포용 파일만 원본과 같은 상대 경로로 `SimpleGame/Data/Environment`에 넣었다.
공용 `palette.mtl`과 환경 항목 카탈로그가 함께 복사되므로 빌드 결과가 별도 모델링 작업 폴더에 의존하지 않는다.
개발 환경에 같은 ID의 원본이 있으면 그 파일을 우선 사용한다. 캐릭터와 선택적 드론 GLB의 전달 방식은 기존과 같다.

- 잔광 지구 건물은 기존 ID로 대응하며 자동 생성 건물은 좌표 기반의 외형 선택을 유지한다.
  모델의 바닥 폭·깊이·높이는 기존 배치에 맞춘다. 건물 이름, 표어, 이름이 들어가던 화면 간판을 제거했다.
  모델 자체의 발광 간판과 게임 진행용 목표 표식은 표시한다.
- 도로와 보도는 원래 8×8 청크의 도로 구획에 맞춰 배치한다. 직선·교차로·코너·횡단보도·골목·보도 모델을 사용하며,
  일부 교차로에는 맨홀 모델을 얹는다. 마을 사이 도로는 원래 타일 마스크를 따르고, 바깥 바닥은 같은 골목 표면을 어둡게 표시한다.
- 가로등·볼라드·방호벽·쓰레기통·벤치는 마을 청크별 최대 하나를 보도에 배치한다.
  도로, 건물, 거점, 보급 상자와 스토리 위치를 피한다. 카메라·배관·네온 간판·환기구는 일부 수제 건물에 부착한다.
- 거점 바닥·벤치·정비 단말·창고 상자, 보급품·전리품 상자, 스토리 단말은 기존 Actor의 표시를 모델로 바꿨다.
  감시 드론도 해당 GLB가 있으면 기존 비행 경로에 표시한다. 임무, 충돌, 상호작용 범위와 원점 이동 규칙은 유지한다.

거리 소품은 SceneGraph가 생성·제거하고, 건물 부착 소품은 부모의 위치와 가림 효과를 따른다.
바닥 메시를 마을의 4가지 패턴과 외곽 도로 마스크별로 한 번 만들고 공유한다.
바닥의 윗면과 도색을 높이순으로 묶어 보이는 청크당 한 번 직접 그리므로, 각 도로 조각을 위한 별도 합성 패스가 없다.
건물과 소품은 기존 HDR 모델 렌더링과 공유 GPU 버퍼를 사용한다. 모델이 비활성화됐거나 읽히지 않으면 기존 바닥과 건물 표시를 사용한다.

`tools/validate_model_assets.py --packaged-only`로 모델링 폴더 없이 패키지, 재질 참조, 도로 6종의 바닥 면,
수제 건물 배치 범위를 정적으로 검사할 수 있다. 게임 빌드·실행·화면 검증은 수행하지 않았다.
