# 1막·NPC 사회·월드 확장 구현 안내

작성일: 2026-10-13. 상태: 소스 구현 및 정적 검사 완료. 빌드·게임 실행·화면·성능 검증은 사용자 확인 대상이다.

## 적용 범위와 진행 순서

확정된 1막의 공통 진행을 다음 단계로 연결했다. 장면은 현재 OpenGL 도형 기반 Actor와 한글 대화 패널을 사용하는 프로토타입 표현이다.

1. 시작 후 사건 현장으로 이동한다. 의료 기업 후손, 피해자, 경호원이 각각 Actor로 표시된다.
2. 현장 접근 시 약 5초 동안 주인공의 조작·전투가 저지된다. 피해자가 쓰러지고 목격 기록이 남는다. 이 실패로 정당성을 감점하지 않는다.
3. 공공 단말에서 `[E]`를 눌러 폭로한다. 기록이 지워지는 결과는 모든 경로에서 동일하다.
4. 피해자 가족과 대화하여 곁에 남거나 가족의 말을 외면하는 선택을 한다. 가해자를 첫 목표로 삼는 진행은 공통이다.
5. 기존 보급·주먹 전투·적 3명 제압·전리품 회수·거점 보고로 준비한다. 훈련과 성장, 레벨 5 칼, 거점 제작·강화·창고를 유지했다.
6. 운송 노동자를 만나 회복제를 남기고 보호하거나 협박하여 접근 단서를 얻는다. 의료 기업이 보스의 생명 유지·사이버웨어·기업 성장에 기여했다는 관계를 확인한다.
7. 목표 위치로 이동해 의료 기업 후손을 전투로 제압한다. 이 캐릭터는 훈련 적의 처치 집계·전리품·반복 재생성에서 제외된다. 도입부에서 미리 공격하거나 대화로 전투를 건너뛸 수 없다.
8. 가해자 곁에서 `[E]`를 눌러 생포·구금과 증언 보존 또는 항복한 가해자의 처형을 선택한다. 전투에서 체력이 0이 된 것만으로 살해를 확정하지 않는다.
9. 기록이 주민·지하 정보망으로 퍼지고 인지도가 상승한다. 저항자와 대화해 반란세력의 형성을 확인하며 1막을 완료한다.

6개 거점의 위치는 `SimpleGame/Data/Story/act1.story`에서 설정한다. 스토리 NPC는 진행 불능을 막기 위해 일반 NPC의 공격·갈취 대상에서 제외했다. 연출 중 경호원의 저지는 제한된 조작으로 표현하며 물리 기반 잡기 애니메이션은 아니다.

생포 방식, 증인 보호의 구체적 수단, 준비 과정의 훈련 연결과 수치는 구현용 초기 설계다. 확정된 중심 줄거리를 바꾸는 별도 설정으로 취급하지 않는다. 보스의 최종 대면과 2~4막의 세부 사건은 미작성·미구현이며, 1막 이후 자유 활동을 이어갈 수 있다.

## 조작

- `[E]`: 스토리 거점·NPC·보급·거점 상호작용. 긴 안내는 E로 넘긴다.
- 대화에서 `[1~3]`: 선택, `[E / Esc]`: 대화 닫기. 대화와 기록 화면에서는 전투·NPC·스토리 갱신을 멈춘다.
- `[J]`: 활동 기록, `[1 / 2]`: 기록 이전·다음 페이지, `[J / Esc]`: 닫기.
- 기존 WASD·Shift·Space·H·M·Tab·거점 숫자키·후처리 조작을 유지한다. 대화·기록 입력이 거점이나 종료 입력보다 먼저 처리된다.
- `[F2]`: 새 게임 초기화. 사망·부활은 진행 기록과 NPC 이력을 유지한다.

## 정당성

정당성은 −100~+100이며 시작값은 0이다. 사건 ID별로 한 번 반영한다. HUD에는 점수를 직접 노출하지 않고 활동 기록과 반응을 보여준다. 수치와 사건 ID는 기존 성능 이벤트 로그에도 남긴다.

| 선택·행동 | 초기 변화량 |
|---|---:|
| 가족을 위로함 / 외면함 | +8 / −4 |
| 증인 보호 / 협박 | +10 / −12 |
| 생포와 기록 보존 / 항복한 가해자 처형 | +8 / −10 |
| 일반 NPC 의료 지원·부품 전달 | +2 |
| 실제 갈취 이력이 있는 높은 악명 NPC 제압 | +3 |
| 충분한 범죄 근거가 없는 NPC 공격 | −15 |
| 일반 NPC 협박 | −10 |
| 자신이 남긴 피해 인정·보상 | +4 |

일반 NPC 관련 긍정 보상 합계는 +12로 제한했다. 같은 주민의 지원과 제압을 반복해 보상받지 못하며, 부정 행위와 주요 선택 기록은 남는다. 죽인 적 수만으로 정당성을 평가하지 않는다. 수치는 아직 플레이 검증 전이다.

현재 정당성은 주민의 두려움, 기록의 평가 문구, 반란세력의 대화에 반영된다. 최종 보스의 인정·부정 분기는 후반 스토리 구현 때 이 기록을 이용한다.

## NPC 직업·행동·악명

| 직업 | 행동 및 상호작용 |
|---|---|
| 주민 | 주변을 이동·휴식하고 위협을 피한다. 의료 지원과 정보 대화 |
| 상인 | 거래 위치를 유지하고 회복제를 판매한다. 8 크레딧당 1개 |
| 약탈자 | 주변 주민에게 접근하여 갈취·피해를 주고 악명이 상승한다. 일부 피해 수습 행동으로 악명 감소 |
| 생산직 | 작업과 운반 위치 사이를 이동한다. 부품 2개 전달 시 보수 5 크레딧, 일회성 |
| 의료인 | 주변 부상 NPC에 접근해 치료한다. 물품 거래와 정보 제공 |
| 정비사 | 작업 장소를 지키고 부품 전달 요청. 플레이어 장비 정비는 기존 거점에서 진행 |
| 경비 | 순찰하며 높은 악명 NPC에 접근해 활동을 중단시키고 악명을 낮춘다 |

악명은 0~100이며 직업만으로 적대성을 부여하지 않는다. 실제 갈취는 +12, 일부 피해 수습은 −6, 지원·작업·정상 거래는 해당 행동에 따라 감소한다. 악명 60 이상이면 플레이어와 적대할 수 있다. 플레이어가 공격·협박하여 신뢰가 −40 이하가 되어도 방어적 적대가 발생한다.

NPC 공격은 예고 위치를 고정한 뒤 판정하므로 이동하여 피할 수 있다. 체력이 0인 NPC는 제압 상태로 남고 반복 경험치를 주지 않는다. 실제 갈취 이력이 있는 제압 NPC의 부품을 주변에서 한 번 자동 습득한다. 일반 시민에게 무조건 전리품을 주지 않는다.

대화에는 직업·현재 활동·악명·플레이어 신뢰를 표시한다. 주변 정보, 거래, 의료 지원, 부품 전달, 협박과 피해 보상 선택이 있다. 자신이 해친 비범죄 NPC에게는 적대 중에도 피해 보상 대화를 시도할 수 있다. 직업에 따른 외형 소품과 활동 표시도 추가했다.

NPC 사회 활동은 플레이어 근처 12타일에서 시뮬레이션한다. 이동은 기존 충돌 판정과 국소 조향을 사용하며 복잡한 길 찾기·전체 도시 시간표는 아니다. NPC를 향한 주먹은 가까운 대상 하나, 칼은 범위 내 대상을 판정하며 같은 공격의 피해 수치를 고정한다.

## 월드 생성

수제 잔광 지구의 건물 중심·랜드마크·바닥 도로는 유지하며, 각 건물의 바닥 외곽을 0.35타일씩 줄여 보행 간격을 넓혔다. 외곽은 다음 방식으로 생성한다.

- 4×4 청크 블록에 걸친 간선 도로를 좌표에서 계산한다. 인접 청크가 같은 도로 규칙을 공유한다.
- 주변 전환 구간에서 기존 골목 도로와 새 간선을 섞어 연결한다.
- 6×6 청크 단위의 주거·시장·광장·생산·기업 구역을 만든다.
- 건물 후보의 위치·폭·깊이·높이·밀도·간판·색을 구역과 좌표에서 결정한다. 도로·다른 건물과 겹치는 후보는 제외한다.
- 같은 자동 생성 청크 안의 건물 사이에는 최소 2.0타일의 간격을 둔다. 간격을 확보할 수 없는 후보는 배치하지 않는다.
- 청크 경계의 보행 여유를 확보하고 서로 다른 직업의 NPC를 배치한다.
- 건물은 동일 좌표에서 동일하다. 일반 NPC·몹 수와 출발 위치는 구역과 새 게임의 인구 시드에 따라 정하며 같은 플레이 중 재방문할 때 유지한다. 활성 범위 밖 지형·Actor는 해제한다.

도로 표현과 건물 배치 검사에 같은 `WorldRoad` 함수를 사용한다. 거대한 전역 타일 좌표를 float로 누적하지 않고 기존 64비트 청크와 작은 장면 좌표를 유지한다. 도로 종류가 달라도 모든 바닥이 기존처럼 이동 가능하다.

## 플레이어 표현과 저장 범위

주인공은 키 큰 마른 실루엣, 긴 기능성 코트, 칼라·스트랩·벨트·장갑·부츠·헤어·얼굴과 제한된 청록 장식으로 그린다. 보행에 따라 팔·다리·코트가 움직인다. 기존 인스턴싱 렌더러로 그리며 생성된 콘셉트 이미지 자체를 런타임 스프라이트로 변환한 것은 아니다.

스토리·정당성·NPC 건강·악명·신뢰·일회성 지원 기록은 실행 중 재방문과 플레이어 부활에 유지된다. 의미 있는 NPC 상태 변화만 ID별 메모리 기록으로 남기며 지형 전체를 보관하지 않는다. 이력의 수는 새 NPC의 상태 변화에 따라 증가한다. 게임을 종료하고 다시 실행하면 진행은 초기화된다. 디스크 세이브는 아직 없다.

## 파일과 분석 자료

- `StoryState.h`, `StoryProgression.cpp`: 단계·선택·정당성·진행.
- `StoryActors.*`: 사건 제어·거점·대화 Actor.
- `NpcBehavior.cpp`, `NpcDialogue.cpp`: 사회 행동과 상호작용.
- `WorldLayout.*`, `WorldStreaming.cpp`: 공통 도로 규칙과 구역 생성.
- `StoryRendering.cpp`: 캐릭터 세부 표현·스토리·대화·기록 화면.
- `Data/Locale/ko.txt`: 새 안내와 대사, UTF-8.
- `tools/validate_story_content.py`: 문구 중복·누락, 동적 키, 사건 좌표, 프로젝트 등록, 장면 정의의 정적 검사. 빌드나 게임 실행을 하지 않는다.

기존 렌더링 CSV/이벤트 로그는 계속 생성된다. `justice_event`와 `npc_action` 이벤트를 프레임 로그의 시간과 함께 분석할 수 있다. 새 상태 표시·문구가 글꼴 캐시 미적중과 업로드에 주는 비용도 기존 프로파일링 지표로 비교한다.

## 사용자 확인 순서

1. 첫 장면에서 임의로 가해자를 공격해도 진행을 건너뛰지 못하는지, 저지 후 단말 목표가 나타나는지.
2. 폭로·가족·훈련·증인·전투·처분·저항자 순으로 1막 완료까지 진행되는지.
3. 두 처분 경로와 증인 선택에 따라 기록과 반란세력 반응이 달라지는지.
4. 대화와 기록 화면의 입력·시간 정지, J 페이지, Esc 닫기를 확인한다.
5. NPC 갈취·회복·순찰·대피·적대 공격과 회복제 거래·부품 전달·피해 보상을 확인한다.
6. 재방문·사망·F2의 상태 유지와 초기화 차이를 확인한다.
7. 양수·음수 외곽에서 배치·도로·충돌과 수제 지구 복귀, 새 NPC 밀도와 성능 로그를 비교한다.

이 검증 시나리오는 사용자 확인 안내이며 자동 실행 지시가 아니다.

최근 일반 몹 생성, 넓어진 건물 간격, 간소화한 HUD 및 마우스 메뉴 조작은 [WORLD_POPULATION_AND_HUD.md](WORLD_POPULATION_AND_HUD.md)를 따른다. 고정 위치의 훈련 적 3명은 제거했고, 훈련의 제압·전리품 목표 3회는 일반 몹 누적 기록으로 유지한다.
